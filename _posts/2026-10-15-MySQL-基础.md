## 使用MySQL

### 查找MySQL的安装路径

```cmd
where mysql
```

### 去对应的bin文件夹打开终端

```cmd
cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"
```

### 登录MySQL

```cmd
mysql -uroot -p
```

## Windows MySQL 常用命令

（分两类：CMD外部命令 + mysql> 里面SQL命令）

> 注意：**SQL语句末尾必须带分号 `;`**，大小写不敏感，推荐大写关键字方便阅读。

### 一、Windows CMD命令（没进入mysql> 之前，管理员CMD）

#### 1. 服务启停（最常用，替换成你的服务名，一般 MySQL80）

```
net start MySQL80     # 启动mysql服务
net stop MySQL80      # 停止mysql服务
```

#### 2. 登录连接数据库

```
mysql -uroot -p        # -u用户名 -p密码，回车后输入密码，不会回显
mysql -uroot -p123456  # 直接跟密码（不推荐，会留下记录）
mysql -uroot -p -h127.0.0.1 -P3306  # 指定主机和端口
```

#### 3. 导入/导出备份（CMD执行，不是mysql内）

```
# 导出整个库（备份）
mysqldump -uroot -p 库名 > D:\backup.sql
# 导入sql文件
mysql -uroot -p 库名 < D:\backup.sql
```

#### 4. 查看mysql版本

```
mysql -V
```

### 二、mysql> 内部SQL命令（登录成功后，mysql>提示符下）

####  库操作

```
SHOW DATABASES;                -- 查看所有数据库
CREATE DATABASE testdb;        -- 创建数据库 testdb
CREATE DATABASE IF NOT EXISTS testdb; -- 不存在才创建（防报错）
DROP DATABASE testdb;           -- 删除数据库
DROP DATABASE IF EXISTS testdb;
USE testdb;                     -- 选中/切换数据库，后续操作都在这个库
SELECT DATABASE();              -- 查看当前正在使用哪个库
```

####  表操作（先 use 库名）

```
SHOW TABLES;                    -- 查看当前库所有表
DESC user;                      -- 查看user表结构（字段、类型）
SHOW COLUMNS FROM user;         -- 和desc等价
CREATE TABLE user(
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(50),
  age INT
);                              -- 创建表
DROP TABLE user;                -- 删除表
DROP TABLE IF EXISTS user;
ALTER TABLE user ADD email VARCHAR(100); -- 新增字段
ALTER TABLE user DROP email;    -- 删除字段
```

####  增删改查（DML，最核心）

```
-- 查
SELECT * FROM user;                     -- 查询全部列
SELECT id,name FROM user;                -- 只查id,name列
SELECT * FROM user WHERE age>18;        -- 条件查询
SELECT * FROM user ORDER BY id DESC;     -- 倒序排序
SELECT * FROM user LIMIT 0,10;           -- 分页，取前10条

-- 增
INSERT INTO user(name,age) VALUES ('张三',20);
INSERT INTO user(name,age) VALUES ('a',10),('b',22); --批量插入

-- 改 ⚠️ 一定要加WHERE！不加会全表更新！
UPDATE user SET age=21 WHERE id=1;

-- 删除 ⚠️ 不加WHERE会清空整张表！
DELETE FROM user WHERE id=1;
TRUNCATE TABLE user; -- 清空整张表，重置自增id，速度更快
```

####  用户与权限

```
USE mysql;
SELECT User,Host,authentication_string FROM user; --查看所有账号哈希密码

CREATE USER 'test'@'localhost' IDENTIFIED BY '123456'; --新建用户
ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码'; --修改密码（MySQL8.0）

-- 授权
GRANT ALL ON testdb.* TO 'test'@'localhost';
FLUSH PRIVILEGES; --刷新权限
```

####  查看系统信息

```
SELECT @@version;          -- mysql版本
SELECT @@basedir,@@datadir;-- 安装目录、数据目录
SHOW VARIABLES LIKE 'port';-- 查看端口号
SHOW VARIABLES LIKE 'character_set%'; --查看字符集
```

####  退出

```
exit;
quit;
```
