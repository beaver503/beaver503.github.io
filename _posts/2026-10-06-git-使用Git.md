# 一、Git 常用命令

提交指定文件夹到指定仓库：

```bash
cd 你的文件夹路径
git init # 初始化仓库
git add . # 添加文件夹内所有文件
git commit -m "init" # 提交并记录提交信息
git branch -M main  # 提交到的主分支
git remote add origin git@github.com:***.git # 提交的远程仓库地址
git push -f origin main # 强制推送到远程仓库，危险，用本地提交历史覆盖远程
git push -u origin main # 完成一次关联 + 推送，之后直接git push就行了
```

最常用的步骤：
```bash
# 创建远程仓库，然后克隆到本地
git clone git@github.com:***.git

# 创建SSH key密钥
ssh-keygen -t ed25519 -C "你的邮箱"
# 复制密钥
cat ~/.ssh/id_ed25519.pub | clip # 粘贴到对应网站

# 测试联通
ssh -T git@github.com
ssh -T git@gitee.com
```

```bash
# 添加仓库地址
git remote set-url --add origin git@gitee.com:***.git
git remote set-url --add origin  git@github.com:***.git (push)
# 删除推送地址
git remote set-url --delete origin git@gitee.com:***.git
# 查看推送地址
git remote -v
```

删除远程指定文件夹：

```bash
# 把 folder_name 换成你的文件夹名，-r代表递归删除整个目录
git rm -r --cached folder_name

# 提交这次删除变更
git commit -m "remove folder_name from remote"

# 推送到github，远程就删掉这个文件夹了
git push origin main
```

# 二、同时在两个平台推送
## 一步清空所有旧密钥（Windows）

打开 Git Bash，直接运行：

```bash
cd ~/.ssh
rm -f id_* known_hosts config
```

现在你电脑里 **所有旧 SSH 密钥全删光了**

干干净净，从零开始

---

## 重新生成 1 个通用密钥（同时给 GitHub + Gitee 使用）

```bash
ssh-keygen -t ed25519 -C "你的邮箱"
```

**一路 3 次回车，不要设置密码！**

---
## 复制新密钥

```bash
cat ~/.ssh/id_ed25519.pub | clip
```

---
## 去两个平台粘贴这个公钥

1. **GitHub** → Settings → SSH and GPG keys → New SSH key → 粘贴
2. **Gitee** → 设置 → SSH 公钥 → 粘贴

---
## 测试是否成功

## 测试 GitHub

```
ssh -T git@github.com
```
## 测试 Gitee

```
ssh -T git@gitee.com
```

都显示成功 ✅
## 先查看你现在的远程地址

```bash
git remote -v
```

你现在应该只有 **github**

---

## 关键：给 origin 添加第二个仓库地址

直接复制运行这条命令：

```bash
git remote set-url --add origin git@gitee.com:***.git
```

---
## 再查看一下（确认成功）

```
git remote -v
```

你会看到：

```plaintext
origin  git@github.com:888.git (fetch)
origin  git@github.com:888.git (push)
origin  git@gitee.com:888.git (push)
```

```bash
# 写错了可以删除最后一个
git remote set-url --delete origin git@gitee.com:888.git
```

✅ **两个 push 地址，成功！**

## 以后提交，只需要一条命令！

```

git push
```

它会 **自动同时推送到 GitHub + Gitee** ✅✅

# 五、绑定上游并推送本次修改

fatal: The current branch main has no upstream branch.
意思：当前本地 main 分支还没有绑定远程 main 分支关联关系。

```bash
git push --set-upstream origin main
git status
```

看输出，如果提示 nothing to commit, working tree clean，代表一切就绪。

在 Obsidian 库根目录确认存在.gitignore文件，内容：
```plaintext
.obsidian/ 
.DS_Store

*.tmp
```

```bash
# 1.初始化本地git仓库 
git init 

#2.关联远程GitHub仓库，把下面链接替换成你仓库的https地址 
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git 

#3.把当前所有文件加入暂存 
git add . 

#4.提交本地版本 
git commit -m "init: 博客仓库初始化"
 
#5.推送到远程main分支（很多github默认分支叫main，不是master） 
git push -u origin main
```

error: src refspec main does not match any
含义：本地不存在叫 main 的分支！

你的 GitHub 仓库默认分支是 master
查看本地分支名称
```bash
git branch
```
如果输出是 * master，代表本地分支叫master，不是 main！

想强制把本地分支名字改成 main（推荐统一用 main，和 GitHub 远端对齐）
```bash
# 先commit，有提交记录之后，重命名分支 
git commit -m "init: blog repo" 
git branch -M main 
git push -u origin main
```
git branch -M main 把当前分支重命名为 main。

如果你 commit 的时候提示配置用户名邮箱（首次使用 git）
```bash
git config --global user.name "yourname" 
git config --global user.email "你的github注册邮箱"
```

# 七、github 443端口连接失败

## 完整教程：Git 切换 SSH 协议（解决 github 443端口连接失败）


> 原理：HTTPS 走 443 端口容易被网络拦截；SSH 使用**22 端口**，部分网络环境连通性更好，配置完成之后不再需要输入账号 / PAT 令牌。 
## 第一步：本地生成 SSH 密钥对

1. 打开 Windows 终端（PowerShell，在你的仓库文件夹或者任意位置都可以）
    
2. 执行下面命令，把邮箱替换成你 GitHub 注册邮箱
    

```bash
ssh-keygen -t ed25519 -C "你的github注册邮箱"
```

> 如果你的旧 OpenSSH 不支持 ed25519，用这条备选：

```bash
ssh-keygen -t rsa -b 4096 -C "你的github注册邮箱"
```

3. 提示 `Enter a file in which to save the key`，**直接回车**，使用默认保存路径
    
4. 提示输入密码（passphrase）：
    
    1. 可以直接回车（不设置密钥密码，最简单，本地电脑安全就没问题）
        
    2. 也可以输入自定义密码，每次推送需要输入密钥密码
        
执行完成，会生成一对密钥：

- 私钥：`C:\Users\你的用户名.ssh\id_ed25519`（**绝对不要分享、上传**）
    
- 公钥：`C:\Users\你的用户名.ssh\id_ed25519.pub`（复制这个文件内容放到 GitHub）
    
## 第二步：复制公钥内容

1. 在 PowerShell 直接打印公钥：
    
```bash
cat ~/.ssh/id_ed25519.pub
```

> 如果是 rsa 密钥：`cat ~/.ssh/id_rsa.pub`

也可以查看文件记事本打开，然后全选复制
2. 把输出的**全部文本**完整复制，从 `ssh-ed25519` 一直复制到末尾邮箱，不要漏掉字符，不要换行。
## 第三步：GitHub 网页添加 SSH 公钥

1. GitHub 网页右上角头像 → Settings
    
2. 左侧菜单找到 **SSH and GPG keys**
    
3. 点 `New SSH key`
    
4. Title：随便写，例如 `Windows PC beaver503`（用来区分设备）
    
5. Key type：保持默认
    
6. Key 框：粘贴刚才复制的一整段公钥
    
7. 点 Add SSH key，完成。
    
## 第四步：本地测试 SSH 连通性

PowerShell 执行：

```bash
ssh -T git@github.com
```

首次连接会提示：

> Are you sure you want to continue connecting (yes/no/[fingerprint])? 输入 `yes` 回车。 成功提示类似： Hi beaver503! You've successfully authenticated, but GitHub does not provide shell access.

看到这句话代表 SSH 密钥配置成功！

## 第五步：修改仓库远程地址，从 HTTPS 切换为 SSH

进入你的仓库目录 `D:\beaver503.github.io`，执行：

```bash
git remote set-url origin git@github.com:888.github.io.git
```

> 验证远程地址是否修改成功：

```bash
git remote -v
```

输出应该是：

```Plain
origin  git@github.com:888.github.io.git (fetch)
origin  git@github.com:888.github.io.git (push)
```

## 第六步：测试推送

```bash
git push
```

✅ 不再需要 PAT 令牌，直接走 SSH 22 端口上传。

回到 Obsidian，打开 Obsidian Git 命令面板：Commit and push 插件会直接使用你已经配置好的 SSH，不需要 Token，不需要填 URL
