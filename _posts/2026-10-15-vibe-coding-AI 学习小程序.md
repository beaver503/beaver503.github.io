### 第 0 ~ 1 期：AI 编程工具准备 + 需求分析

- 开通 GitHub Copilot 免费会员，在 VS Code 中登录验证
- 确认能够使用 Claude Opus 等付费大模型
- 人工需求分析：目标用户、核心痛点、MVP 边界
- 如何区分 MVP 功能和扩展功能
- 为什么选微信小程序作为产品形态
- 用 Gemini Deep Research 做 AI 需求调研和竞品分析
- 用对话思考模式交叉验证需求可靠性
- 合并 AI 与人工的分析结果，确认《需求分析文档》

### 第 2 期：环境准备

- 安装 Node.js 环境
- 安装并配置 GitHub Copilot 插件
- 配置 MCP：Firecrawl（联网搜索）、Context7（最新技术文档）、Playwright（浏览器自动化）
- 安装 Agent Skills 扩展 AI 能力
- 安装微信小程序开发者工具
- 安装 Python 环境

### 第 3 期：小程序知识

- 为什么开发小程序，而不是 App 或网页
- 三种产品形态的优缺点对比
- 原生开发和跨端框架开发的区别
- 小程序开发学习路线
- 建立「先用 AI 快速做出来、再系统学习」的学习心态

### 第 4 期：方案设计

- 让 AI 辅助技术选型（小程序框架、AI 大模型、前后端技术栈）
- 人工审核并推翻 AI 的选型建议，最终选定 Taro
- 确定 DeepSeek + FastAPI + LangChain 技术栈
- 设计出题提示词和结构化输出格式
- 设计核心开发流程和 MVP 开发边界
- 生成并人工确认《方案设计文档》

### 第 5 期：UI 原型设计开发

- 为什么要先做 HTML 原型，再开发小程序
- 安装并配置 Claude Code，接入国内大模型
- 让 Claude Code 和 GitHub Copilot「赛马」，同时产出两套原型
- 结合两套方案的优势深度优化
- 确定 UI 风格和设计系统
- 用原型作为后续开发的视觉基准

### 第 6 期：核心功能开发

- 用 Git 管理已有成果，为 AI 开发上保险
- 确认 MVP 核心功能和开发顺序
- 编写开发提示词，让 AI 生成前后端代码
- Taro 脚手架初始化 + FastAPI 项目搭建
- 接入 DeepSeek 大模型实现 AI 出题
- 人工测试配合 AI 修复 Bug
- 跑通「输入 → 出题 → 答题 → 报告」核心业务流程

### 第 7 期：用户系统开发

- 用户系统需求分析，大功能拆批次、排优先级
- 微信静默登录 + JWT 鉴权方案设计
- 理解 openid 和 JWT 各自的作用
- 准备 MySQL 数据库，让 AI 自主建表并存档 SQL
- 申请微信小程序测试号
- 开发登录、个人中心、闯关历史功能
- 约束 AI「只扩展、不破坏现有功能」
- 测试验证并看懂小程序调试中的「正常报错」

### 第 8 期：Bug 修复

- 系统梳理 17 个核心 Bug，形成测试报告
- 「集中修复 + 自主验收」的批量修 Bug 思路
- 封装【图片理解】技能，让 AI 读懂 Bug 文档里的截图
- 如何用 Network 和 Console 面板精准报 Bug
- 让 AI 一次性批量修复，人工回归测试

### 第 9 期：AI 生成题目优化（联网搜索）

- 什么是 Harness Engineering，如何给 AI 搭好脚手架来对抗上下文断片
- 用 OpenSpec 做规范驱动开发，管理本次需求
- 为什么大模型自己出的题会过时
- 用 LangGraph 构建 ReAct Agent，接入 Tavily 联网搜索
- 搜索失败的降级策略和上下文长度控制
- 用「异步任务 + 轮询」攻克微信请求超时难题
- 用 OpenSpec 归档功能沉淀文档

### 第 10 期：RAG 知识问答

- 什么是 RAG，为什么大模型需要外挂知识库
- 四种主流 RAG 方案对比（Naive、Advanced、Modular、Agentic）
- 本项目方案设计：向量库 + Embedding 模型 + LangGraph Agentic 路由
- 文档上传、多格式解析、分块和向量化入库
- 按用户隔离向量集合，按文档过滤检索
- 基于知识库文档出题
- 测试验证与归档提交

### 第 11 期：AI 生图 + 对象存储

- 什么是对象存储，为什么不能直接用生图接口返回的链接
- 开通并配置腾讯云 COS
- AI 生图模型选型和配图提示词设计
- 多题并发生图与信号量控制
- 每日生图额度限制和成本控制
- 临时图片链接转存对象存储获取永久链接
- 测试验证与归档提交

### 第 12 期：发布上线

- 前后端分离项目的部署思路
- 三种后端部署方案对比（Serverless、容器托管、云服务器）
- 为什么选择微信云托管
- 让 AI 生成 Dockerfile 并部署到微信云托管
- 本地服务上云：MySQL 换成云数据库，向量库的坑
- 区分开发和生产环境的接口地址配置
- 打包构建小程序并上传，设置体验版
- 申请「深度合成 - AI 问答」服务类目及所需资质
- 完成 ICP 备案、配置服务器域名白名单
- 提交代码审核并正式发布上线
- 上线后踩坑排查（AppSecret、云调用冲突、域名白名单）

### 扩展篇：项目扩展思路

- 趣味出题提示词优化，让题目更有意思
- 边出题边答题，用流式输出降低等待感
- Query Expansion 增强联网搜索效果
- 分享海报和裂变传播设计
- AI 角色扮演和沉浸式对话闯关
- 自适应难度调节
- 游戏化激励体系（连胜、排行榜、成就、勋章）
- 艾宾浩斯遗忘曲线复习提醒
- 多模态解析（图表、语音读题）
- 安全限流、敏感词和成本控制
- 引入 ORM 提升工程化水平
- 商业化方向（会员付费、企业培训、流量主广告）
