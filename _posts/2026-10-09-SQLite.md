# SQLite 特点与优势

SQLite 是**嵌入式、无服务端**的轻量级关系型数据库，整个数据库就是一个磁盘文件，不需要独立后台进程。

##  核心特点

1. **无服务端（Serverless）** 没有独立数据库服务进程，程序直接读写磁盘上的 `.db` 文件；客户端和数据库在同一个进程内，不用网络通信。
2. **单文件数据库** 整个数据库（表、索引、数据、元信息）打包成**单个文件**，复制、备份、迁移直接拷贝文件即可。还有临时内存模式 `:memory:`，数据库完全放在内存，关闭就销毁。
3. **零配置** 不用安装、不用初始化、不需要账号密码、不用管理用户权限，引入库就能直接使用。
4. **ACID 事务支持** 支持事务、回滚、提交，保证原子性、一致性、隔离性、持久性；依靠写前日志（WAL）提升并发读写。
5. **跨平台** 一套数据库文件可以在 Windows / Linux / macOS / Android / iOS 之间直接通用。
6. **类型动态（弱类型）** 列是**类型亲和**，不是强约束。例如声明 `INTEGER` 的字段，也可以存入字符串（和 MySQL/PostgreSQL 强类型不一样）。
7. **支持大部分标准SQL** 支持 SELECT/INSERT/UPDATE/DELETE、JOIN、子查询、索引、触发器、视图，仅少数高级SQL特性缺失。
8. **库极小** 编译后的库文件很小，几十KB到几百KB，非常适合嵌入程序。

## ✅ 优势

1. **部署简单** 不需要单独部署数据库服务，打包应用一起分发，移动端、桌面软件首选。
2. **低资源消耗** 不常驻后台进程，占用内存、CPU很低，适合资源受限设备（手机、嵌入式设备、IoT）。
3. **读写简单，单机性能不错** 单线程场景下，查询速度很快；WAL模式支持**读和写并发**（写会串行）。
4. **备份方便** 直接复制db文件就能备份，也自带 `VACUUM` 整理碎片、回收空间。
5. **开发成本低** 绝大多数编程语言都自带或很容易接入SQLite（Python内置、C/C++、Java、JS等）。

## ⚠️ 局限（配套了解，方便选型）

- **不适合高并发写**：同一时刻只能一个写操作，大量并发写入会锁等待。
- **不适合多客户端远程访问**：没有网络服务，多机器共享同一个db文件容易损坏。
- **大数据场景受限**：单库上限理论可达140TB，但千万级以上大表、复杂多表聚合性能会下降。
- **用户权限薄弱**：权限依赖文件系统，没有数据库级别的细粒度账号权限。

## 📌 适用场景

✅ 本地桌面软件、手机App本地存储、小型单机工具、嵌入式设备、测试开发本地数据库、网站低流量单机数据存储

❌ 高并发Web后端、多服务器共享数据库、高频大量写入业务
